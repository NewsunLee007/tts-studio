## 运行架构

- Worker `tts-studio` 托管网页与声音服务目录，Containers 运行 Express / FFmpeg。
- R2 `tts-studio-audio` 保存朗读片段与导出成品，公开音频链接保留原来的 ID 和路径。播放、下载、HEAD、Range 与缓存校验直接由 R2 响应。
- 大于 64 MiB 的音频按 32 MiB 分块上传，每块校验 SHA-256；容器内临时文件在保存后清理。
- Worker secrets 保存存储鉴权与已有 DeepSeek 配置。网页填写的 TTS 密钥仍只保存在浏览器当前会话，镜像与 Git 不包含密钥。
- 域名采用 `tts.newsunenglish.com/*` Worker 路由，Cloudflare DNS 为已代理的 A 记录 `192.0.2.1`。这是无源站占位，全部请求在 Cloudflare 内处理；不要移除 Worker 路由。

## 使用方式

进入“声音服务”选择阿里云百炼，填写 API Key，先测试连接并试听短句。默认 Qwen3 Instruct；选择 Qwen-Audio 3.1 时还需北京工作空间 ID 和专用 3.1 音色。确认音色后返回文稿，拆分、生成、下载。

网页已整合阿里、MiniMax、豆包 2.0、硅基流动及原有国内服务的注册、密钥和官方价格入口。浏览器系统语音用于免费预览；托管 API 的赠金或限额试用不标为永久免费。模型资料与链接见 [README](../README.md)。

文稿和编辑状态保存在原浏览器本地，保持同一域名，不等同于跨设备同步。
